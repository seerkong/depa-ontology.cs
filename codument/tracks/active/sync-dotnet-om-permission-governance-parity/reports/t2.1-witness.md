# T2.1 Strict Graph Witness Evaluator

## Implemented

- `ConstraintLogic.CheckAccessAsync` now normalizes `AsOf` once and only lets a policy contribute to allow or deny after its witness is `Matched`.
- Permission paths accept JSON arrays, slash paths, and arrow paths. Each hop resolves through relation aliases and must name a defined relation; malformed and unknown paths are invalid and fail closed.
- Witness traversal uses only outgoing edges, reads current or the normalized `AsOf` graph, orders frontier ids and neighbors ordinally, and keeps the first complete canonical witness. `[]` is a witness only when subject and resource ids are equal.
- Typed `PermissionWitnessDiagnostic`, evaluated-policy JSON, and matched-policy JSON now expose the same canonical witness hops.
- `PermissionGovernanceParityFixtures` adds malformed-path denial, alias/arrow traversal, reverse-direction denial, empty-path self/non-self coverage, and deterministic first-witness selection.
