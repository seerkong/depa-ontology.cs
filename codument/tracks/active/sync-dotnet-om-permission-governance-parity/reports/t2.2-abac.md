# T2.2 Entity-Aware Temporal ABAC and Field Visibility

## Implemented

- `CheckAccessAsync` resolves both subject and resource types once, normalizes `AsOf` once, and passes that same temporal point through every ABAC property read.
- ABAC references now resolve `subject.type`, `resource.type`, subject/resource properties, and existing id/action compatibility references. Property reads use `GetPropertyAsOfAsync` when an `AsOf` is present, including normal attribute-alias resolution.
- Bare and `literal:` values are parsed as JSON literals when valid (`true`, numbers, quoted strings, arrays, objects, and `null`); otherwise they remain string literals. Equality and ordered `>`, `>=`, `<`, and `<=` comparators are evaluated over the resolved JSON values.
- Missing properties, malformed references, field references in an invalid position, and unsupported operators fail closed with deterministic typed diagnostics. ABAC rules are read in lexical `(left_ref, op, right_ref)` order.
- `field.<name> hide <truthy-expression>` now adds `PermissionFieldVisibility.Hidden` and the matching `Explanation.fieldVisibility` entry only after the path and every non-hide predicate match. Hide predicates do not turn an otherwise matching policy into a denial; deny policy precedence remains unchanged.

## Fixture Coverage

`PermissionGovernanceParityFixtures` now covers:

- Subject type and subject/resource property comparisons with quoted JSON string and boolean literals.
- Numeric ordered comparison, deny override, and temporal property reads at the normalized `AsOf` point.
- Missing property fail-closed diagnostics.
- Typed and JSON field visibility agreement, plus a conditional hide rule that proves a rejected policy cannot add a hidden field.
- Existing invalid-path/operator/reference and stable-order checks continue to run.

The fixture invocation was moved ahead of the legacy permission seed assertions in `Program.cs`; this lets the full harness exercise the strict T2.2 fixture before reaching the intentionally deferred migration failure.
