# T2.6 Bun Authorization AsOf Normalization

## Scope

Eliminated repeated timestamp parsing inside Bun `checkAccess` temporal reads while preserving the public `getPropertyAsOf` and `getNeighborsAsOf` APIs.

## Implementation

- Added private normalized-time helpers for property and neighbor reads.
- Public temporal helpers still validate their arguments and normalize the caller-supplied timestamp before delegating to the private helpers.
- `checkAccess` now passes its boundary-normalized `asOf` to the private neighbor helper for witness traversal and to the private property helper for ABAC resolution.
- Nested computed property reads reuse the already normalized timestamp as well.

## Regression Seam

The Bun permission conformance suite now instruments `Date.parse` during a temporal authorization request with both a graph witness and a `subject.role` ABAC read. It verifies that the coarse input `2024-06-01` is exposed as `2024-06-01T00:00:00.000Z` and that parsing occurs exactly once.
