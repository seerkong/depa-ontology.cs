# T2.5 ABAC Reference and AsOf Closure

## Scope

Implemented the two explicit gaps from `p2-attractor-002` without changing public APIs, track state, or mission state.

## Changes

- C# ABAC shape validation now rejects `subject.id`, `action`, `resource.id`, and `resource.field` as `malformed_reference`. The rejection happens before request-value resolution, so these compatibility references cannot contribute either an allow or a deny.
- C# authorization now passes the request-boundary normalized `AsOf` through internal temporal neighbor and property readers. Public `GetNeighborsAsOfAsync` and `GetPropertyAsOfAsync` retain their existing normalization and validation behavior.
- Added C# typed and JSON diagnostic coverage for all four prohibited references.
- Added the matching Bun conformance case and fail-closed `malformed_reference` diagnostics for the same reference surface.
