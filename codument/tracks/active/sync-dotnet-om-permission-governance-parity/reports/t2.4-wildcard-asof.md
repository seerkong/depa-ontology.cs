PASS

## Changes

- C# permission evaluation now requires exact action equality and no longer adds `*` as a resource scope. Wildcard action/resource policies therefore cannot grant access or override an explicit matching allow with a deny.
- Explicit `Type.field` scopes remain supported when the caller requests that exact field; this preserves the existing public permission contract without treating wildcard resource values as a match.
- `CheckAccessResult.AsOf` and the JSON explanation's `asOf` now share the single normalized timestamp used by witness and ABAC evaluation. Fail-closed missing-subject/resource results receive the same projection.
- Added Bun and C# regressions for wildcard allow/deny behavior, plus normalized temporal explanation assertions.
