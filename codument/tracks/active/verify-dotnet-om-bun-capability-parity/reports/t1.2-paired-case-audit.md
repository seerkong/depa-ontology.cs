# T1.2 Paired-Case Audit

## Verdict

`NO_GAP`

The independent audit found four executable-evidence gaps in Bun tests. All
four were decision-free test omissions over behavior already present in the
runtime, and all were repaired. No production implementation changed, no
frozen decision was reopened, and no remaining G01-G14 row relies solely on
prose where executable behavior is available.

Full runtime suites were intentionally not run in T1.2. Fresh full-suite and
focused-fixture execution remains the P2 gate.

## Findings

### Resolved: G12 did not execute the complete no-init API contract

`om-existential-fixpoint.test.js` proved that `checkExistentialRules` and
`applyExistentialRules` were safe before `initSchema`, but did not call
`listExistentialRules`. The .NET fixture already asserted all three operations.

The Bun no-init case now asserts that list, check, and apply all return safe
empty results. The focused run passed.

### Resolved: G13 Bun guardrails were implementation-only evidence

Bun source validated behavior owners, constraint scopes, and interceptor
phases before persistence/registration, but the previously cited schema suites
did not execute the rejection paths. This left the Bun side of G13 dependent
on source inspection and prior prose.

`om-action-schema.test.js` now rejects an unknown owner, unsupported constraint
scope, and invalid interceptor phase; proves all three metadata relations stay
empty; then executes a valid interceptor and proves the rejected callback did
not fall back into the `before` registry.

### Resolved: G14 lacked a Bun explicit-parent-clear test

`om-type-hierarchy.test.js` covered omitted options preserving a parent but did
not exercise `{ parentType: null }`. It now proves explicit null removes the
ancestor, returns a null parent in the hierarchy, and makes the detached type a
root. This directly pairs with .NET `TypeParentPatch.Clear`.

### Resolved: G14 lacked a direct Bun value-inference API test

`inferValueType` was exported and exercised indirectly by write validation,
but no test called the public function. `om-exports.test.js` now asserts
`String`, `Number`, `Bool`, `Json`, and `Unknown`, including non-finite numbers.
