# T1.1 Public Surface Characterization

## Scope

This characterization covers the G13/G14 boundary without changing production
source, track state, or mission state. The executable fixture is
`cozo-lib-dotnet/tests/PublicSurfaceParityFixtures.cs`, selectable with
`COZO_OM_TEST_FOCUS=public-surface`.

## Passing Baseline

- The legacy nullable `CozoOm.DefineTypeAsync` overload preserves an existing
  parent when `parentType: null` is supplied. This is the compatibility behavior
  that D5=C must retain while introducing a separate explicit clear operation.
- Invalid behavior owner, invalid constraint scope, and invalid interceptor
  phase all fail before persistence and leave neither metadata rows nor callback
  registry entries. This verifies the existing G13 guardrails rather than
  reopening them as implementation work.

## Red Characterizations

The fixture deliberately asserts the following current absences by reflection,
so it remains executable before the public contract is implemented:

1. `CozoOm` has no public `ValidateConstraintsAsync` facade.
2. `CozoOm` has no public general `TraverseAsync` facade.
3. `CozoOm` has no public `InferValueType` facade.
4. `CozoOm` has no explicit parent patch/options API carrying a Keep/Set/Clear
   intent; nullable `DefineTypeAsync` cannot distinguish omitted from clear.

These are the intended red G14 gaps for T1.2/T2.1. The Bun reference already
exports `inferValueType` and `traverse`, and distinguishes omitted parent from
explicit `null`; no Bun test change was needed to characterize the C# public
surface.
