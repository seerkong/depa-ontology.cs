# T1.2 Paired Case Audit

## Scope

Audit date: 2026-07-18.

This audit compares the frozen, observable G15-G17 contracts against their
source and executable tests. It treats D6-D8 as the only allowed intentional
differences. It does not reopen API-shape, cancellation, or wire-envelope
decisions, and it does not modify the mission.

## Issues First

### Fixed: D6 legacy-adapter sharing was only partially exercised

The D6 decision freezes Bun plain-runner calls as compatibility adapters over
one explicit legacy runtime. The existing lifecycle test proved that the
legacy adapter is separate from an explicit runtime, but it did not prove the
observable cross-database consequence of the single legacy adapter: a callback
registered by one plain runner can resolve a matching persisted definition in
another plain-runner database, and no-argument `clearRegistry()` clears that
shared adapter for both.

Added the minimal Bun-only compatibility case:

- `cozo-lib-bun/__tests__/om-runtime-registry-lifecycle.test.js`
  `plain runners intentionally share one legacy callback adapter across databases`

The test uses two independent in-memory databases, persists the matching action
definition in each, registers only once through the left plain runner, executes
through the right plain runner, then proves no-argument clear invalidates both
lookups. This is intentionally Bun-only under D6: .NET has no legacy global
free-function adapter and instead exposes an instance-owned `CozoOm` registry.

No runtime implementation change was required.

## Conclusion And Scope Boundary

After the D6 compatibility case above, no frozen and observable G15-G17
contract relies only on prose or one-sided unintentional support. The remaining
one-sided surfaces are precisely D6 legacy adapters and D8 Bun snapshot
envelopes, both explicitly resolved in the mission decisions. This task changed
only its required report, `T1.2` status/acceptance metadata, and the minimal
Bun lifecycle test.
